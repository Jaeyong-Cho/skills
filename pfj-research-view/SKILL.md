# Research Note Viewer

Find and display markdown research notes. Generate HTML report on request.

## Step 1: Resolve note

If user names a topic, slug, or date — find matching note:

```bash
ls $PFJ_PATH/research/**/*.md 2>/dev/null | grep <keyword>
```

If no match or no input, list all notes:

```bash
ls $PFJ_PATH/research/**/*.md 2>/dev/null
```

Ask which note to open if multiple candidates.

## Step 2: Display note

Read and print the markdown note content inline. Summarize in one line: topic, date, confidence.

Ask via `AskUserQuestion`: "What next?" — options:
- "Generate HTML report"
- "Edit this note"
- "Done"

## Step 3: Generate HTML report (if requested)

Follow `../pfj-grill/REPORT.md` for structure, styling, and generation rules.

Read the markdown note. Derive slug and date from filename.

Save: `$PFJ_PATH/research/YYYY/MM-DD-<slug>.html`

```bash
mkdir -p $PFJ_PATH/research/YYYY
```

Header: note title · date · confidence.
Footer: `Generated by pfj-research-view · date · slug`

Always include: observation, interpretation, key findings with reasoning, open questions.
Include when warrants: alternative explanations, what was ruled out, next experiments.

```
Report: $PFJ_PATH/research/YYYY/MM-DD-<slug>.html
```

## Step 4: Edit note (if requested)

Apply user's changes to the markdown note directly. Re-display updated content. Offer to regenerate HTML if one exists.
