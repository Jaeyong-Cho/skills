# Daily Retention Report

Scan research notes. Calculate retention. Show what's due for review.

## Step 1: Scan notes

```bash
ls $PFJ_PATH/research/**/*.md 2>/dev/null
```

Extract date from each filename (`YYYY/MM-DD-<slug>.md`). Calculate age in days from note date to today.

## Step 2: Classify each note

Review points (days since written): 1, 7, 16, 35, 62, 225, 365, 730, 1825, 3650, 9125, 18250

Formula: `R(t) = e^(-t/S)` — t = days in current interval, S = stability (starts at 1, doubles after each review)

For each note determine:
- **Stage** — which interval it's in (between which two review points)
- **Current retention %** — R(days since last review point) × 100
- **Next review date** — next review point from note date

Group:
- **Due today** — age within ±1 day of a review point
- **Overdue** — past a review point, retention below 50%
- **Upcoming** — next review within 7 days
- **On track** — not due yet

## Step 3: Generate HTML report

Follow `../pfj-grill/REPORT.md` for structure and styling.

Save: `$PFJ_PATH/research/reports/YYYY/retention-MM-DD.html`

```bash
mkdir -p $PFJ_PATH/research/reports/YYYY
```

Header: `Retention Report · YYYY-MM-DD` · total notes · due count.

Sections (in order):
1. **Overdue** — title, age, retention %, days overdue; highlight urgency by retention color
2. **Due today** — title, age, retention %, review stage
3. **Upcoming (7 days)** — title, next review date, days until due
4. **All notes** — full table: title, date, age, stage, retention %, next review date

For each note in overdue + due today: show full note content inline — observation, interpretation, key findings, open questions, next experiments.

Forgetting curve chart per note (canvas, no libraries):
- X axis: log scale, 1d → 18,250d. Labels: 1d, 1w, 1mo, 6mo, 1y, 2y, 5y, 10y, 25y, 50y.
- Y axis: 0–100% retention.
- One curve segment per interval (each resets to 100% at review point, decays with that S).
- Mark today. Highlight current segment. Show retention %.

Footer: `Generated by pfj-retention · YYYY-MM-DD`

```
Report: $PFJ_PATH/research/reports/YYYY/retention-MM-DD.html
```
