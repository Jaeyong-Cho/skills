# Problem Define

## Goal

Turn vague pressure into a clear problem statement, then find solutions.

## Phases

### 1. Dump
Ask user to describe situation freely. No structure yet.
- "What's going on? Say anything."
- Accept feelings, observations, complaints — all valid input.

### 2. Probe
A problem = gap between current state and expected state. Two things to check:

**Check the gap:**
- "What specifically feels wrong?"
- "When did this start? What changed?"
- "Is this the real problem, or a consequence of something deeper?"
- Use 5 Whys: keep asking "why" until root cause emerges.

**Check the expectation:**
- "What do you expect instead?"
- "Why do you expect that?"
- If expectation is wrong/unrealistic → problem is the expectation, not the gap.

Stop when user says "yes, that's it" or answer stops changing.

### 3. Define
State the real problem in one sentence. Confirm with user.
> "Real problem: [X] because [Y], which causes [Z]."
- Do not proceed until user confirms this is right.

### 4. Discuss Solutions
Brainstorm options. For each:
- What does it solve?
- What does it cost / risk?
- How hard to do?

Help user pick one. End with concrete next action.
