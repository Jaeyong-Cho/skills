# Research Note Viewer

Find notes matching user's scope. Display inline. Generate combined HTML report on request.

## Step 1: Resolve scope

Infer scope from user's natural language:

- **Single note** — user names a slug, title, or specific date+topic → find one note
- **By date** — "today", "yesterday", "this week", specific date → all notes from that date range
- **By topic** — keyword or tag → search across all notes for matches
- **All** — no filter → list everything

```bash
ls $PFJ_PATH/research/**/*.md 2>/dev/null
```

**Single note:** `grep -l "<keyword>" $PFJ_PATH/research/**/*.md 2>/dev/null`

**By date:** filter filenames by date prefix (`YYYY/MM-DD-*`)

**By topic:** `grep -rl "<keyword>" $PFJ_PATH/research/**/*.md 2>/dev/null`

If multiple candidates and scope is ambiguous, list matches and ask which to include.

## Step 2: Display

Read all matched notes. For each, print:
- Title, date, confidence
- Observation (one line)
- Key findings (bullets)

Show count: `Found N note(s) matching scope.`

Ask via `AskUserQuestion`: "What next?" — options:
- "Generate HTML report"
- "Done"

## Step 3: Generate HTML report (if requested)

Follow `../pfj-grill/REPORT.md` for structure, styling, and generation rules.

Derive report slug from scope (e.g., `2026-05-24`, `react-hooks`, `all`).

Save: `$PFJ_PATH/research/reports/YYYY/MM-DD-<scope-slug>.html`

```bash
mkdir -p $PFJ_PATH/research/reports/YYYY
```

Header: scope description (e.g., "Research · 2026-05-24" or "Research · react hooks") · note count · date generated.
Footer: `Generated by pfj-research-report · date · scope`

**For each note in report:**
- Title, date, confidence badge
- Observation → Interpretation → Key findings → Open questions

**Always include:**
- **Summary table** — note title, date, confidence, one-line finding
- **Full note sections** — each note expanded in full

**Include when content warrants (multiple notes):**
- **Common themes** — recurring findings or questions across notes
- **Confidence distribution** — how many high/medium/low
- **Open questions aggregated** — all unresolved questions across notes

```
Report: $PFJ_PATH/research/reports/YYYY/MM-DD-<scope-slug>.html
```
