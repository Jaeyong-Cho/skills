# Observation Report

Run observe/ scripts. Collect output. Report findings, patterns, anomalies.

## Step 1: Grill

Run `grill-me` focused on: what the user wants to understand, what they expect to find, what would count as an interesting or unexpected result. No maximum questions — keep going until fully understood.

## Step 3: Discover scripts

```bash
ls observe/ 2>/dev/null
```

If no `observe/` or empty → tell user to run `/pf-observe` first.

List scripts found. Ask via `AskUserQuestion`: run all or select specific ones.

## Step 4: Run scripts

For each selected script:

```bash
cd observe && python <script>.py   # or bash <script>.sh
```

Capture stdout, stderr, exit code. Print output per script as it runs.

Pass `--debug-path observe/output --debug-level debug` if the script accepts it.

Note: pass / fail / no output for each.

## Step 5: Analyze output

For all collected output, look for:
- **Confirmed** — values or patterns that match expectations
- **Unexpected** — values wrong, too high/low, missing, or inconsistent
- **Patterns** — recurring signals across multiple scripts
- **Anomalies** — things that appear unrelated but stand out
- **Unresolved** — output that doesn't clearly point anywhere

Do not dismiss anything as irrelevant before examining it.

Ask via `AskUserQuestion`: "Generate the HTML report?" — if no, skip and stop.

## Step 6: Generate HTML report

Follow `../pfj-grill/REPORT.md` for structure and styling.

Save: `.pf/reports/observe/YYYY/MM-DD-<slug>.html` (slug from topic or "observe")

```bash
mkdir -p .pf/reports/observe/YYYY
```

Header: `Observation Report · YYYY-MM-DD` · scripts run · finding count.
Footer: `Generated by pf-observe-report · date`

Sections:
1. **Scripts run** — name, exit code, one-line summary
2. **Findings** — each finding: what was observed, which script, what it means
3. **Unexpected / anomalies** — highlighted separately
4. **Patterns** — signals that appeared across multiple scripts
5. **Unresolved** — output that needs further investigation

```
Report: .pf/reports/observe/YYYY/MM-DD-<slug>.html
```
